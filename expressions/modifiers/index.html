XGen Modifiers & SeExpr Library

XGen's true power lies in SeExpr—the scripting language it uses to drive procedural variation, masks, and modifiers. While SeExpr is incredibly flexible, remembering exact syntax for randomizing cuts or adding stray hairs can interrupt creative grooming flow.

The Expressions tab in GroomKit serves as an interactive SeExpr library of pre-written, high-performance snippets. More than just a text clipboard, GroomKit can automatically build and configure XGen modifiers for you.

SeExpr Expression Library

GroomKit categorizes SeExpr expressions based on specific grooming needs:

  • Basic Math: Randomize values using Random Sliders, Density Masks, and Random Boolean Masks.
  • XGen Clumping: Advanced setups for cutting hair percentages within clumps or adding procedural noise offsets.
  • Random Noise: Specialized expressions for root noise, flyaways, and stray hair isolation.
  • Wind & Procedural Cuts: Logic for wind direction, structural randomization, and automated hair cutting.
  • Advanced Math: Complex expressions combining IDs, noise patterns, and custom map overrides.

For a detailed walkthrough on applying modifiers to your grooming workflow, view our XGen Video Tutorials.

The Magic FX Button ✨

The core of the Expressions tab is the fx button, designed to automate the manual setup of XGen modifiers.

Instead of manually copying text, clicking the fx button executes a background script that:

  1. Creates a new XGen Modifier (e.g., Noise or Cut) within active Description.
  2. Configures attributes like Magnitude, Frequency, and Masking directly based on the chosen snippet.
  3. Generates and bakes data for Clumping modifiers, automatically processing clumping points and region maps.

Example: Automating Flyaway Hair

To quickly implement flyaways, locate "Flyaway Noise" under the Random Noise tab and click the fx icon. GroomKit automatically creates the modifier, applies the stray hair SeExpr, sets the Ramp scale, and updates the viewport in one click.

Editing & Saving Custom SeExpr Snippets

The text fields in GroomKit are fully editable, allowing you to customize math or values for your specific pipeline.

  • Refresh Icon: Restores the snippet to the GroomKit default code.
  • Copy Icon: Copies the SeExpr code to clipboard for manual use in the Maya XGen expression editor.
  • Write expressions to file: Located at the bottom of the UI, this saves your custom modifications to disk. GroomKit will automatically load these tailored expressions in future sessions.

Python Commands for Expressions

You can also trigger expression saving via the GroomKit Python API:

Expression Commands

Save expressions to disk via Python: 

import groomkit

# Save all current UI expressions to the local library
groomkit.expression.write_expressions()
