GroomKit for AutoDesk Maya Documentation

Specialized 3D Grooming & Procedural Hair Plugin for XGen (Maya 2027+)

Introduction

GroomKit is an all-in-one 3D grooming toolkit designed to streamline Maya XGen styling, procedural hair generation, and advanced curve-guide control for character artists.

By building on the native XGen Core engine and addressing common grooming bottlenecks, GroomKit makes creating realistic, strand-based hair much more approachable. The plugin consolidates the complex Maya grooming workflow into a compact, intuitive interface, minimizing the need to jump between menus and helping Groom Artists stay focused on the creative styling process.

Key Features

  • GroomKit Profiles: Generate and manage real-time hair Cards, Tubes, Twists, Curls, and complex Braids dynamically. Adjust length, width spans, coils, and UVs procedurally.
  • Interactive Curve Tools: An extensive set of unified curve-guide brushes (Draw Append, Draw Cut, Draw Edit, and Geometry Shaping) controlled via interactive mouse gestures for intuitive hair sculpting.
  • XGen Guides Binding: Bind XGen guides or Maya curves to lattices and procedural geometry. Compensate guide length, sync changes, and non-destructively shape your grooming setups.
  • XGen Live Mirror: Enable dynamic X-axis symmetry in real-time as you sculpt and place XGen guides across your character's mesh.
  • Painting & Masking: A detachable palette window that makes changing brush profiles, toggling mirror painting, generating XGen clumping maps, and color-flooding accessible with a double-click.
  • Shader Presets: Apply hair shader presets to multiple descriptions with a single click, or save/load your own custom look-dev presets locally to speed up rendering pipelines.
  • Extended Hotkeys: A clean interface for GroomKit commands, including an auto-register button to set up your custom grooming hotkeys instantly.
  • Reusable Snippets: Utility tools that automate frequent XGen grooming tasks, such as region mapping, duplicating descriptions, and transferring mesh positions.
  • SeExpr Expressions: Fully customizable, UI-driven SeExpr snippets (Random Wind, Random Cut) that allow you to preview, replace, and create advanced XGen modifiers with a single click.
  • Simulation Shaping: A unified gravity draping interface that works across standard Maya curves, XGen guides, and GroomKit Profile geometry.

And more!
