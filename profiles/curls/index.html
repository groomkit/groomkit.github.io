Curls Profile

The Curls Profile generates spring-like helper geometry along your curves to drive XGen curly hair grooms. It uses procedural sweep logic to create the underlying structures required to extract and bind guides for wavy or tight curly hair descriptions.

Curl Settings

0. Curl Presets:

  • Apply Presets: Quickly populate parameters using predefined values.
  • System Presets: Spring, Spiral, and Linear presets.
  • User Presets: (Update in next version).

1. Profile Settings:

  • Count: Set the number of strands in the curl.
  • Length / Steps: Adjust the overall length and subdivision resolution.
  • Phase: Offset the starting position of the curl pattern.
  • Geometry: Switch between output geometry types: Curves, Cards, and Tubes.

2. Shape Settings:

  • Frequency / Ramp: Control how tightly the curl spirals along the curve.
  • Randomize: Add organic length variation across the strands.
  • Noise & Seed: Add displacement to the core shape to break up perfect symmetry.

3. Rotation Settings:

  • Rotate: Rotate the curl around the path curve.
  • Rotate Ramp: Control the rotation or twist along the curve falloff.

4. Scale Settings:

  • Scale: Adjust the overall thickness of the curl.
  • Scale Ramp: Shape the thickness of the curl along the curve falloff.

Interactive Gestures:

  • Ctrl + MMB: Scale.
  • Shift + MMB: Frequency.
  • Ctrl + Shift + MMB: Geo Scale.

Bind Guides: XGen Guides Binding

Cards Settings

5. Card Settings:

  • Length Spans: Adjust vertical edge subdivisions.
  • Width Spans: Adjust horizontal subdivisions.
  • Arch: Bend two sides of the card.
  • Rotate: Rotate the card around the path curve.
  • Scale: Adjust the card's width multiplier.

Tubes Settings

6. Tube Settings:

  • Length Spans: Set the number of vertical edge subdivisions.
  • Width Spans: Set the number of horizontal subdivisions (sides).
  • Rotate: Spin the tube geometry globally around the path curve.
  • Scale: Adjust the global thickness of the tube.

Interactive Sculpt Integration

With the Interactive Sculpt Tool enabled, you can use mouse gestures to intuitively shape (e.g., scale, rotate, and twist) the selected layers.
