Cards Profile

The Cards Profile generates flat procedural planes along your curves to serve as a high-precision source for XGen Guide binding. This is the standard method for extracting clean, parallel edge data to drive the orientation and flow of hair descriptions.

Card Settings

1. Profile Settings:

  • Length (%): Trim card length from the tip.
  • Length Spans: Adjust vertical edge subdivisions.
  • Width Spans: Adjust horizontal subdivisions.

2. Shape Settings:

  • Arch: Bend two sides of the card.
  • Scale: Adjust the card's width multiplier.
  • Scale Ramp: Shape the width using a curve falloff.

3. Rotation Settings:

  • Rotate: Rotate the card around the path curve.
  • Twist: Twist the card around the path curve.
  • Twist Ramp: Adjust twist falloff along the curve.

Interactive Gesture:

  • Ctrl + MMB: Scale.
  • Shift + MMB: Rotate.
  • Ctrl + Shift + MMB: Twist.

Bind Guides: XGen Guides Binding


Standardize Interface

All GroomKit Profile types share one unified and consistent interface layout. Getting familiar with one profile type allows you to easily navigate the others.
