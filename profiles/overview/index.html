GroomKit Profiles: Procedural Hair Geometry for Maya

Examples of procedurally generated hair cards, tubes, and braids in Maya.

The GroomKit Profiles system is a non-destructive, procedural geometry generator built directly into Maya. Whether you are creating flat Hair Cards for real-time game engines, stylized Tubes, or complex Braids, Profiles allow you to drive heavy geometry using simple and lightweight path curves.

This feature combines geometry shaping, curve extraction, and guide binding into a single, intuitive workflow. By keeping your entire grooming process inside Maya, GroomKit eliminates the need for external software, allowing artists to stay focused on creative styling.


Profiles Window & UI Structure

GroomKit Profiles utilizes a Layer-based workflow. By grouping guide curves into a Layer and assigning a Profile type, GroomKit automatically generates the corresponding mesh. Because the system is fully procedural, you can modify your curves using Interactive Sculpting Tools, and the generated geometry will update in real-time.

The Profiles interface is organized into four main sections for efficient groom management:

  1. Profile Types: Toggle between 5 distinct generation types: Hair Cards, Tubes, Twists, Curls, and Braids.

  2. Layers & Tags Management: Organize and tag your groom layers. Supports multi-selection and context-menu operations.

  3. Layer Operations: Utility tools for grooming, including Bind Guides, Lattice Deform, Duplicate, and Geometry Extraction.

  4. Layer Settings: Procedural controls for the mesh. Use sliders and curve ramps to adjust scale, rotation, frequency, and width dynamically.


Layers & Tags Management

The Layers UI is the primary dashboard for your groom. It is custom-built to handle complex tasks such as visibility toggling, geometry operations, and viewport color-coding for better scene organization.

Essential Layer Controls

Every layer provides instant access to these essential grooming toggles:

  • 1. Layer Indicator: Access advanced functions to pin or bake a layer.
  • 2. Layer Name: Auto-assigned name for the procedural layer.
  • 3. Layer Color: Set a custom viewport display color for easy identification.
  • 4. Layer Tag: Categorize layers using a 3-letter tagging system.
  • 5. Visibility Button: Cycle display modes: Visible (V), Hidden (H), Template (T), and Path (P).
  • 6. Color Bucket: Randomize viewport colors across selected layers.
  • 7. Geometry Icon: Manage bound Guides or select the XGen Description.
  • 8. Remove Button: Safely delete the layer while preserving original curves in the xgCurves group.
  • 9. Auto Select: Automatically highlights layers in the UI based on your Maya viewport selection.
  • 10. Master Controls: Global toggles that affect all layers simultaneously.

Performance Note: Auto Select

Toggle off Auto Select when not in active use. Leaving it enabled causes GroomKit to constantly query the viewport for selections, which may impact performance in heavy scenes.

Cycling between display modes and procedural layer colors.


Layer Context Menu

Right-click any layer name to access management functions for duplicating or transferring settings between layers.

Quick access to core management actions:

  • Edit Layer: Open detailed procedural parameters.
  • Copy/Paste Layer: Transfer all parameters and curve ramps between layers.
  • Duplicate Layer: Create an exact replica of the layer and its settings.
  • Delete Layer: Remove the procedural setup from the scene.


Layer Geometry Menu

Right-click the Geometry Icon (grid/sphere) to access tools for geometry extraction, animation prep, and XGen guide utilities.

Specialized tools for interacting with the generated mesh:

  • Snap Layer: Conform the layer's guides to the character's surface.
  • Extract Layer: Convert procedural data into standard Maya polygons.
  • Animate Layer: Setup the groom for dynamic simulation or character rigging.

For layers bound to XGen guides, additional utilities are available:

  • Hide/Select Guides: Quickly manage guide visibility to reduce clutter.
  • Select Description: Locate the tied XGen Description node in the Outliner.


Multi-Scene Workflow

The Copy-Paste function works globally across different Maya instances. You can easily transfer complex hair layers between scenes or maintain a backup of your layer settings.
