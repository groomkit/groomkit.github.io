GroomKit Profiles: Advanced Operations & XGen Workflow

Procedural tube-based grooming workflow across profile types.

The Operations section provides a robust suite of utilities for duplicating, mirroring, extracting, and animating your grooming layers. It serves as the central hub for XGen guide binding, macro shaping, and geometry extraction, supporting seamless multi-selection and tag-based filtering for complex Maya grooms.


XGen Guides Binding

The Guide Binding workflow connects XGen Guides directly to the edges of your procedural profile geometry. This provides a stable, one-click solution for converting procedural hair cards or tubes into guide-driven XGen descriptions.

Binding Options:

  • Bind Button: Executes topology-wise extraction and binds XGen guides to the curves.
  • Layers Count: Enables volume-based extraction. This is particularly useful for generating guides that fill the inside area of large hollow tubes.
  • Bake Guides: Bakes the guide positions so they become completely independent from the geometry layer.
  • Remove Button: Removes the bound guides and clears the binding setup from the layer(s).
  • Note: Right-click the Bind Guides button to access the advanced Bind Options menu.

Workflow Consistency

The Operations frame provides a unified interface that works consistently across all Profile Types (Cards, Tubes, Braids, etc.).

Lattice Deformation

Using the Maya Lattice Deformer within GroomKit is the most efficient way to adjust the macro shape of your groom. It allows you to modify the silhouette of multiple layers simultaneously, replacing hours of manual curve sculpting.

Lattice Options:

  • Lattice Button: Applies a 3x3 Lattice Deformer. Clicking again to accept and bakes the deformation result to the original selection.
  • Preset Buttons: Quick-switch between resolutions (2x2 to 5x5) for either broad shaping or localized detail tweaks.


Duplication & Mirroring

GroomKit’s mirroring tools allow you to flip hair geometry across Maya's world space while maintaining all procedural settings.

Duplicate Options:

  • New Layer: Choose to create a unique profile layer or merge clones into the existing active layer.
  • Duplicate Button: Clones selected layers while retaining all custom parameter settings and curve ramps.
  • Flip X / Z: Instantly mirrors geometry across the X or Z axis. You can choose to flip the current layer or generate a new mirrored version.


Static Geometry Extraction

The Extract feature is perfect for baking procedural setups into raw, static Maya geometry—ideal for exporting to game engines, passing to other pipeline, or finalizing a groom.

Extraction Options:

  • Extract Checkbox: Automatically groups and organizes all extracted assets within the xgExtract group.
  • Paths Button: Extracts the clean underlying path curves from the selected layers.
  • Edges Button: Generates edge-based curves from the profile geometry (perfect for guide creation).
  • Geometry Button: Converts the procedural profile into standard Maya static meshes.

Organized Hierarchy

GroomKit ensures consistent naming conventions. Extracted assets are organized under the xgExtract group and named based on their parent layer (e.g., xgCardLayer1_extract).

Pinning to Base Mesh for Animation

The Animate Pin feature allows you to attach procedural profiles to a deforming character mesh. Unlike standard guides, GroomKit uses a UV-based node system to bind the layer, ensuring the hair follows the character's movement perfectly during animation.

Animate Options:

  • Base Mesh: Attaches to the mesh assigned in the GroomKit Interactive Window.
  • Pin Button: Binds the layer to the UV coordinates of the mesh. The layer indicator turns Red when pinned.
  • Unpin Button: Breaks the binding and registers the curves' current world-space position.


Baking Custom Nodes (Curls & Braids)

GroomKit uses specialized procedural nodes for Braids and Curls. To ensure your scene renders on machines without GroomKit installed (or for final delivery), use the Bake feature to convert these nodes into standard geometry.

Bake Options:

  • Bake Button: Converts procedural curls/braids into static geometry. The indicator turns White.
  • Unbake Button: Reverts the static mesh back into a fully editable procedural GroomKit node.
  • Note: While baked, geometry still follows the path curves but loses localized procedural parameter updates until unbaked.
  • Note: This mechanism is specific to Curls and Braids geometry types.
