Tubes Profile

The Tubes Profile creates closed cylindrical helper geometry around your curves. It provides a volumetric source for extracting XGen guides, allowing you to drive guide distribution and volume for dreadlocks or thick hair clumps with precision.

Tube Settings

1. Profile Settings:

  • Length (%): Adjust the overall length of the tube from the tip.
  • Length Spans: Set the number of vertical edge subdivisions.
  • Width Spans: Set the number of horizontal subdivisions (sides).

2. Scale Settings:

  • Scale: Adjust the global thickness of the tube.
  • Scale X / Scale Z: Scale the width and depth independently to flatten the tube.
  • Scale Ramp: Shape the thickness of the tube along the curve falloff.

3. Rotation Settings:

  • Rotate: Spin the tube geometry globally around the path curve.
  • Twist: Twist the geometry along the path curve.
  • Twist Ramp: Control the intensity of the twist along the curve falloff.

Interactive Gesture:

  • Ctrl + MMB: Scale.
  • Shift + MMB: Rotate.
  • Ctrl + Shift + MMB: Twist.

Bind Guides: XGen Guides Binding

Interactive Sculpt Integration

With the Interactive Sculpt Tool enabled, you can use mouse gestures to intuitively shape (e.g., scale, rotate, and twist) the selected layers.
