GroomKit Hotkeys

Grooming is a highly visual, iterative process. Every time you have to move your mouse away from your character to click a button in the UI, you break your creative flow state.

GroomKit provides a comprehensive list of Python commands that mirror its UI functions. By binding these to your keyboard or tablet express keys, you can keep your cursor on your mesh and groom at lightning speed.

Auto-registered commands in the Hotkey Editor.

Auto Registration

In the GroomKit UI under the Hotkeys tab, you will find a Register to Current Hotkeys Set button at the bottom of each category. Clicking this will automatically register all GroomKit commands into your active Maya Hotkey set.

You can then open Maya's native Hotkey Editor via

Windows > Settings/Preferences > Hotkey Editor, navigate to the Custom Scripts section under the GroomKit category, and easily assign your preferred keys.

  • Single Click: Copy Python command to clipboard.

General & Preview

Essential viewport and XGen management tools to keep your scene running smoothly.

Action
Python Command
 Description
XGen Window import groomkit; groomkit.xgen() Opens or focuses the native XGen UI.
Update Preview import groomkit; groomkit.preview() Refreshes the generated XGen primitives.
Clear Preview import groomkit; groomkit.clear_preview() Clears the generated XGen primitives.

Core Sculpting Tools

The bread and butter of traditional XGen guide manipulation.

Action
Python Command
 Description
Sculpt Guides import groomkit; groomkit.sculpt() Standard sculpt brush with selection.
Create Guides import groomkit; groomkit.create() Add new guides onto the mesh surface.
Normalize Guides import groomkit; groomkit.normalize() Normalize curves cvs spacing.
Rebuild Guides import groomkit; groomkit.rebuild() Rebuilds CVs without changing shape.
Rebuild Guides (8) import groomkit; groomkit.rebuild(8) Rebuilds guides specifically to 8 CVs.
Mirror Guides import groomkit; groomkit.mirror() Mirrors guides symmetrically on X-axis.
Copy Shape import groomkit; groomkit.shape('copy') Copies the shape of the selected guide.
Paste Shape import groomkit; groomkit.shape('paste') Pastes copied shape onto target guides.
Lock Length import groomkit; groomkit.lock_length() Preserves guide length during editing.
Volumetric Falloff import groomkit; groomkit.volumetric() Toggles a volumetric selection radius.

Interactive Brushes

GroomKit provides plug-and-play hotkeys for the interactive brush toolset along with a radial menu. Binding these commands to your preferred key combinations is highly recommended for an intuitive grooming experience.

Action
Python Command
 Description
Sculpt Brush import groomkit; groomkit.sculpt() Standard sculpt brush with soft selection.
Create Brush import groomkit; groomkit.create() Standard create brush to add new curves.
Draw Brush import groomkit; groomkit.draw() Freehand draws curves directly onto mesh.
Add Brush import groomkit; groomkit.add() Click and drag to plant clusters of hair.
Cut Brush import groomkit; groomkit.cut() Dynamically trim curve with mouse gesture.
Attach Brush import groomkit; groomkit.attach() Attach new segments to selected guides.
Move Brush import groomkit; groomkit.move() Slides guides across boundary surface.

 Description

 Description

Automated commands and buttons to work seamlessly with Profiles layers.

Instant access to the corresponding layer by selecting bound guides.

Python Command
 Description
