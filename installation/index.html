GroomKit Installation

Setting up the GroomKit Maya plugin is a quick and straightforward process. Follow the steps below to perform the initial installation and configure the built-in auto-updater so your XGen grooming workflow always has access to the latest features.

Initial Installation Steps

  1. Download the latest version of the GroomKit plugin from your personal library on the official Gumroad store.

  2. Once downloaded, extract the .zip archive and navigate to the folder that matches your current Autodesk Maya version (e.g., 2027).

  3. Inside this version folder, click and drag the dragdropinstaller.py script directly into your active Maya window.

  4. The script will automatically install the plugin and register the GK shelf in Maya for easy access.

  5. To take advantage of the Auto Update feature, open the Check for Update window via GroomKit's top-right menu. Fill in the Email and License Key provided to you at the time of purchase.

Using GroomKit Auto-Updater

Once your license is linked, you can quickly check for and install future GroomKit updates directly within Maya, eliminating the need to manually re-download files from Gumroad.

Auto Update Behavior

When updating to the latest release, the plugin will attempt to install the version automatically. In cases where Maya has locked the plugin files in memory, a popup will appear with brief instructions guiding you to the newly downloaded folder so you can use the dragdropinstaller.py script to complete the update manually.

Auto-Update Troubleshooting

If dragdropinstaller.py raises the following error:

Maya has locked the existing files. To resolve this, perform a clean manual installation:

  1. Close Maya.
  2. Go to Documents/maya/<version>/ (e.g., 2027).
  3. Delete the scripts/groomkit folder.
  4. Delete the plug-ins/groomkitplugin.py file.
  5. Restart Maya and drag the installer script in again.
