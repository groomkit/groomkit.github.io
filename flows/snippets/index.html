GroomKit Snippets

GroomKit Snippets is a comprehensive collection of automated tools designed for 3D character artists working in Maya. By handling multiple frequently used steps in an automated, repeatable manner, these tools allow artists to work at a higher creative level and focus on adding artistic value to the groom project.

XGen Snippets

Useful for duplicating XGen descriptions and region mapping.

  • Set Region Map as Guide Color Map: Uses root colors from painted regions to drive guide color. Randomize bounds control shade values for visual separation.
  • Set Region Map as Density Mask: Uses a simple expression to drive density based on painted regions.
  • Duplicate & Setup Description: Duplicates descriptions to new positions while preserving curves and modifiers. Ideal for inheriting modifiers before setting up complex expressions.
  • Reference Usage: Advanced Region - Density mapping.

Transfer Snippets

Useful for posing characters or moving bounding meshes without using the native Maya Transfer Attributes.

  • Transfer Positions Between Meshes: Easily transfer guide positions by selecting a Source and Target mesh, streamlining the process of moving grooms across geometries.

Custom Snippets

Provides automated guide placement for an optimal initial layout.

  • Distribute Roots Uniformly: Arranges selected curve/guide roots in a circle, estimating the radius from their initial layout.
  • Apply Modifiers Stack: Create a pre-configured modifiers with customizable number of Clumping, Noises and Cut modifiers.
  • Generate Internal Curves: Interpolates curvature from outer shell guides to a centroid guide to plant new curves. Outputs Maya curves first for stability; click To Guides when satisfied to finalize.
    • Layers count: Number of layers from the outer shell to the centroid.
    • Amount: Total curves generated per layer.
    • Curvature: Curvature influence from outer shell guides.


Continuous Improvement

This module is designed to become more robust and feature-rich over time to handle frequently encountered grooming tasks.
