GroomKit Tools

GroomKit Tools provides a set of curve manipulation utilities designed specifically for hair and fur grooming in Maya. These tools automate common operations such as scattering, shaping, snapping, and transforming multiple curves to streamline the overall grooming workflow.

Curve Fill

Tools for curves generation within empty spaces or along specific geometries.

  • Tube: Generates a central curve from a cylindrical mesh or scatters curves within a volumetric space defined by selected boundary curves.
  • Card: Generates evenly spaced curves between two boundary curves or across a flat polygon card. Useful for converting polygon hair cards into curve-based grooms.
  • Deform: Offsets curves outward along the underlying mesh surface normals to resolve geometry clipping, utilizing a preserve setting to keep root positions locked in place.

Curve Snap

Attaches curve roots to the closest point on a designated base mesh.

  • Snap to Base Mesh: Evaluates the root position of selected curves and translates them precisely onto the nearest geometry.
  • Retain & Falloff: Controls the structural preservation of the curve during the snapping process. Retain protects the upper curve shape, while Falloff determines the transition blend from the snapped root into the rest of the strand.

Curve Scatter

Distributes curves uniformly across a selected mesh based on area-weighted sampling.

  • Reference Curve: Utilizes a designated guide or curve as a structural reference. Generated curves inherit its overall shape and orientation.
  • Smart Distribution: Spatially calculates curve placement based on mesh surface area to prevent dense overlapping, requiring inputs for length, total curve count, and CV count.
  • Symmetry: Mirrors the generated curves across the Object or Global X-axis to establish symmetrical grooming bases.

Curve Transform

Utilities for selecting and transforming multiple curves in bulk.

  • Random Select: Selects a randomized percentage of curves from the current selection pool based on a slider value.
  • Pivot to Root: Snaps the transform pivot of all selected curves directly to their respective root coordinates.
  • Batch Mode: Configures tools to use local object pivots and smooth soft-selection, enabling simultaneous local scaling or rotation across multiple selected curves.

Clump / Spread

Modifies the spacing of selected curves by pulling them toward or pushing them away from a central axis.

  • Clump & Spread: Applies an inward (clump) or outward (spread) translation to selected curves based on a Reference curve. If no reference is provided, an average centroid is automatically calculated.
  • Profile Ramp: Dictates the strength and falloff of the clump or spread effect along the length of the curve, from root to tip.
  • Strength: A multiplier for the overall intensity of the clump or spread operation.


Workflow Application

These tools can be used sequentially. For instance, applying Curve Scatter to generate a base layout, using Curve Transform (Batch Mode) for initial orientation, and applying Clump / Spread for final profile adjustments.
