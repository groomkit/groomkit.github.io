Interactive Add

Quickly populate empty areas by drawing new curves directly on the surface.



Add Brush

Tool Settings

  • Drag Interval: Determines how far you must drag the mouse before a new curve is spawned.
  • Use Interpolate: When enabled, the tool scans the surrounding curves within the Distance radius and intelligently averages their length and shape for the newly created curve.
  • Curve CVs: Sets the number of control points the generated curves will be built with.
  • Scatter Mode: Spawns a randomized cluster of curves inside the brush radius instead of a single curve.
  • Scatter Density: Controls how many curves are generated per interval when Scatter Mode is active.
