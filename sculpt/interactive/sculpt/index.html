Interactive Sculpt

Multifunction tools for curve sculpting and profile shaping.



Sculpt Brush

Brush Controls
  • LMB (Left Mouse Button): Move and shape curves.
  • MMB (Middle Mouse Button): Smooth curves locally.
  • Ctrl + LMB (Drag): Adjust brush radius size.
Tool Settings
  • Lock Root: Keeps the base of the curve firmly attached to the Base Mesh while sculpting.
  • Lock CVs: Determines exactly how many control vertices from the root upwards remain stiff and locked in place.
  • Sensitivity: Adjusts the strength and falloff intensity of the soft-selection.
  • Smooth: Determines the strength of the smoothing operation when using MMB.

Core Curve Sculpting

  • Base Mesh is required for scalp root snapping.
  • Sensitivity Slider: Adjusts brush falloff for precise local control.
  • Lock CVs: Freezes root vertices to preserve initial volume and trajectory during block-outs.

Sculpting Procedural Geometry

  • Root snapping fully supports procedural braid geometry.
  • Smooth Slider: controls the intensity of the relaxation effect.
  • Local Smoothing: Hold MMB (Middle Mouse Button) to smooth curves within the brush radius.

Advanced Interactive Gesture

  • Shaping profiles directly in the viewport for an intuitive, slider-free workflow.
  • Interactive shaping is supported for Card, Tube, Twist, Curl, and Braid profiles.


Interactive Profiles

The Sculpt brush features specialized modifiers to procedurally adjust Interactive Profiles in the viewport using mouse gestures

  • Ctrl + MMB: Scale profile radius.
  • Shift + MMB: Rotate profile geometry.
  • Ctrl + Shift + MMB: Twist profile geometry.
  • Ctrl + Shift + MMB (Curl & Braid): Scale inner tube geometry.
