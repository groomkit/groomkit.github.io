Interactive Tools for Maya Curves & XGen Guides

The Interactive Tools module is the core of GroomKit's fluid 3D grooming workflow. It provides a unified, brush-based toolset designed to work seamlessly with both native Maya Curves Sculpting and XGen Guides Brushes without manual context-switching required.



Base Mesh (Crucial)

Before using the Interactive tools, it's generally better to assign the Base Mesh for predictable behavior. This tells GroomKit which surface the curves and guides belong to, allowing the tools to calculate accurate surface snapping, normal orientation, and root locking correctly. When a geometry is set, the tools will exclusively reference this mesh and ignore operations on other background geometries.

  1. Select your character's scalp or body geometry.
  2. Click the Set Mesh button in the Interactive menu.

Enable, Disable, and Clear

You can temporarily disable surface snapping without losing your mesh assignment. Right-click the Set Mesh button to reveal a popup menu where you can Enable/Disable the active mesh, or Clear it entirely.

Interactive Radial Menu

For optimal layout efficiency, the Interactive Tools menu functions as a detachable floating panel. Click Detach Interactive Window in the top-right menu to position your brushes adjacent to your 3D workspace, leaving the main window open for other interfaces.

You can also access the toolset instantly by registering it as a Radial Marking Menu (Ctrl + Shift + MMB) or by using the complete suite of tool-specific Maya hotkeys.

🖌️ Interactive Toolset

The Tool Settings frame will update accordingly to the selected tool context.

Sculpt Brush

Multifunction tools for curve sculpting and profile shaping.

Add Brush

Quickly populate empty areas by drawing new curves directly on the surface.

Cut Brush

A fluid, slide-to-cut tool. Click and drag left/right on a curve to trim its length dynamically.

Draw Brush

Draw freehand curves on the screen plane or directly onto the Base Mesh.

Attach Brush

Click and drag to connect two curve segments or adjust an existing attachment.

Move Brush

Slide existing curves or guides fluidly across the surface of the Base Mesh without altering their original shape.

Important Note

Avoid using the Undo command (Ctrl + Z) while generating or duplicating XGen guides. This action triggers an unavoidable limitation that causes Maya to crash.
