Paint Tools: XGen Masks & Region Mapping

GroomKit Paint interface provides a simple yet versatile toolset to cover all essential painting steps in a typical XGen grooming workflow.


Simple Interface

  • Brush Profiles: Quickly switch between Gaussian, Soft, and Solid brush profiles.
  • Symmetry Toggle: Instantly mirror strokes across the X-axis to quickly block out base masks.
  • Primary Colors: 8 pure colors for clean region maps. Left-click to pick, or Right-click to flood the mesh.
  • Percentage Shading: Right-click White or Black to select exact grayscale opacities (20%–100%) for consistent effect maps.

Additional Colors

  • Randomize Color Palettes: The additional colors found in Utils/Preview can provide an easy color lookup experience.



Advanced Region - Density Mapping

This workflow lets you use region maps as density maps to prevent duplicate painting. It offers exact control over where hair grows and to which region it belongs, which is particularly beneficial for procedurally tube-based grooming.

Using Region map to drive Density control.

Workflow steps:

  1. Locate the XGen snippets under Flows/Snippets.
  2. Apply both of the following snippets:
    • Set Region Map as Guide Color Map
    • Set Density Mask from Region Map


Important Guideline

Save Frequently

Due to the inherent instability of XGen's baking tools, it is highly advisable to save your project and back up your files frequently during the painting phase to prevent potential data loss.
