Sculpt Settings: Core Grooming Tools XGen

The Sculpt panel is your primary hub for foundational 3D character grooming operations. Whether you are manipulating native Autodesk Maya Curves or XGen Guides, GroomKit unifies these actions into a single, intuitive interface, keeping your focus on the viewport rather than technical menus.

Quick access using XGen buttons.

XGen Viewport Buttons

At the very top of the Sculpt tab, you will find three essential buttons with added functionality for rapidly managing XGen guide display directly in the Maya viewport.


Right-click on the Preview or Clear buttons to access the corresponding context menus containing essential viewport and guide management functions.

The XGen button serves as a quick shortcut to access and manage the main XGen workspace alongside GroomKit.

  • Click: Open the native XGen Window.
  • Double Click: Close all tabs and resize the GroomKit window.

The Preview button allows you to generate interpolation previews for your hair descriptions, as well as easily reveal and unlock guides.

  • Click: Toggle description preview.
  • Double Click: Preview all descriptions.
  • Right Click Menu: Show collections guides, Show description guides, Unlock description guides

The Clear button provides options to remove generated hair previews, as well as hide or lock guides to declutter your viewport.

  • Click: Clear description preview.
  • Double Click: Clear previews for all descriptions.
  • Right Click Menu: Hide collections guides, Hide description guides, Lock description guides

Selection Tip

You can enable Auto Select to quickly switch between XGen descriptions right in the viewport.

General Grooming Settings

The Settings foldout contains the standard operations you'll use constantly while shaping your hair and fur grooms.

Sculpt Modifier Settings

  • Lock Length: Locks hair length while sculpting to prevent accidental stretching and maintain volume.
  • 3D Volumetric: Uses a 3D brush sphere to select only nearby hair, preventing accidental grabs on the opposite side of the head.
Quick access to Tool Settings checkboxes.

Base Sculpting Tools

All buttons are applicable for both XGen guides and Maya curves, depending on your current selection.

  • Sculpt: Activates the default Maya/XGen sculpting context. (Note: For advanced grooming, see Interactive Tools).
  • Create: Activates the Add Primitives tool to plant guides on the mesh.
  • Copy / Paste Shape: Select a source guide and click Copy, then select target guides and click Paste to instantly transfer the exact curvature.

Normalize Curves

The Normalize tool redistributes the Control Vertices (CVs) of your selected curves or guides evenly along their length. Maintaining clean curve data is essential for a smooth and predictable groom.

Rebuild Resolution

Rebuilding allows you to change the resolution (CV count) of your guides or curves while preserving their original shape, distributing the new CVs evenly along the curve's length.

  • Rebuild Slider: Manually dial in the exact number of CVs you want.
  • Quick Presets (8, 16, 24): Instantly rebuild selected curves to common resolutions with a single click.


Hotkey Commands

You can bind these core functions to your Maya Hotkeys (Windows > Settings/Preferences > Hotkey Editor). Make sure the language is set to Python for these scripts to work.

Settings Commands

XGen Buttons: 

import groomkit; groomkit.xgen()

import groomkit; groomkit.preview()

import groomkit; groomkit.clear_preview()

Sculpt Settings: 

import groomkit; groomkit.sculpt()

import groomkit; groomkit.create()

import groomkit; groomkit.mirror()

import groomkit; groomkit.volumetric()

import groomkit; groomkit.lock_length()
