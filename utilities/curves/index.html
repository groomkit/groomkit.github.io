Maya Curves Utilities

The Curves utilities foldout is a powerhouse for hair translation in Maya. Whether you are building a groom from proxy geometry or simply need to manage native Maya curves before converting them into XGen guides, this section provides everything required to extract, clean, and convert your curve data efficiently.

One-click curve extraction from existing hair assets


Extract Curves from Edges

Select a contiguous edge loop on a polygon mesh. GroomKit will rip it off and convert it into a clean, rebuilt NURBS curve. Available options:

  • CVs Count: controls extracted curves resolution

Extract Selected generates curves directly from the selected contiguous edge loops.


Extract Curves from Cards

Select flat polygonal hair cards to serve as the proxy geometry. You can dictate exactly where the curves are generated along the card's surface. Available options:

  • CVs Count: controls extracted curves resolution
  • Curves Count: controls the number of extracted curves

Extract Center extracts a single, perfect core curve running down the middle of the card.

Extract Sides extracts two curves along the outer boundaries of the card.

Extract Shell extracts a perimeter of curves wrapped around the surface. You control the density with the Curves Count slider.


Extract Curves from Tubes

Select 3D cylindrical hair meshes. GroomKit analyzes the volume of the tubes to generate core, surface, or concentric interior curves. Available options:

  • CVs Count: controls extracted curves resolution
  • Curves Count: controls the number of extracted curves
  • Layers Count: controls the number of extracted layers

Extract Center extracts a single, perfect core curve running down the middle of the tube.

Extract Shell extracts a perimeter of curves wrapped around the surface. You control the density with the Curves Count slider.

Extract Layers generates concentric rings of curves inside the volume of the tube. Controlled by the Layers Count slider.

Additional Extraction Options

Once you have chosen your extraction method, GroomKit offers several additional options and parameters to refine the resolution, organization, and orientation of the generated Maya curves.

Option Description
Hide Meshes Automatically hides the original proxy geometry after extraction to organize your viewport.
Merge Curves Groups all extracted curves into a single, clean xgExtract group in the Outliner.
Flip Direction Reverses the U/V calculation if your curves are generating sideways.

Procedural Workflow

Currently, to make use of the curve extraction engine, it's required your proxy geometry is standard and has extractable topology. Estimated curve extraction may be implemented in future versions.

Further more, GroomKit Profiles support non-destructive tube-based grooming, allowing you to block out your character's hair, extract it to guides, and shape them procedurally for complex XGen hairstyles without ever leaving Maya.

Topology Note

Set the CVs Count slider to 0 to inherit the exact CV count from source geometry.


General Maya Curve Operations

Quick utilities to sanitize your curve data before groom generation.

  • Toggle CVs: Instantly shows or hides the Control Vertices of the selected curves without digging into Maya's display menus.
  • Reverse Curves: Reverses the root-to-tip direction of the curve. (Crucial: XGen assumes the first CV is the root. If your hair is growing into the head, use this!)
  • Select Roots: Automatically selects the first CV (cv[0]) of all currently selected curves.
  • Rebuild Curves: Opens Maya's native Rebuild Curve options for manual tweaking.
Toggle Curve CVs.
Select Roots and Reverse Curves.


Convert Maya Curves to XGen Guides

Instead of navigating nested UI layers in the standard XGen window, you can swiftly execute the curve-to-guide conversion directly from this panel using the following options:

  • Delete: Automatically deletes the original Maya curves after guide generation.
  • Dynamic Link (Preserve): Maintains the source Maya curves and creates a procedural link, ensuring XGen guides inherit any subsequent edits.
  • Add Guides: Executes the conversion based on your current configuration.
Insert XGen guides using GroomKit interface.


Hotkey Commands

Bind these to your hotkeys (Python mode) to speed up your extraction and conversion workflow.

Curves Commands

Extract Curves (Uses current UI settings): 

import groomkit; groomkit.extract.extract_curves()
Reverse Selected Curves: 
import groomkit; groomkit.curves.reverse_curves()
Select Roots: 
import groomkit; groomkit.curves.select_roots()
Convert Curves to Guides: 
import groomkit; groomkit.curves.to_guides()
