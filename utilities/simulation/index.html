Simulation Shaping

GroomKit enables gravity draping to aid manual hair sculpting by wiring up curve-guide shaping to Maya's simulation engine-driven physics.

The Simulation module temporarily wraps your curves in Maya's Nucleus physics engine. This enables dynamic draping, accurate mesh collisions, and streamlines baking the simulation results back into the original XGen guides.

Hair Simulation Setup

Use the Simulation module to quickly conform strands to reference geometry using natural physics.

  • Simulate: Automatically builds the physics rig and begins simulating selected guides. Acts as a play/pause toggle.
  • Rewind (Simulate RMB): Rolls the timeline back to the start position.
  • Clean Up: Discards the simulation data and removes the physics stack.
  • Apply: Bakes the simulation result to selected guides and removes the physics stack.
Simulate XGen guides and preview update.

Apply Collision: Select your target geometry (body/head) and click this to generate an nRigid collider. This prevents simulation pass-through and ensures hair correctly collides with the character's surface.

Simulate with collision object.

Advanced Gravity Controls

Adjust gravity parameters of physics solver for customized results.

  • Apply Collision: Assign additional meshes to block the simulation.
  • Gravity Sliders: Modify the global force (G) and vector direction (X, Y, Z) to simulate gravity or wind pulls.
  • Retain Sliders: Blend the simulation with your original sculpt to prevent volume collapse at the roots.
  • Nucleus*: Access the native Maya attribute editor for global physical settings.

Partially Simulate

For realistic draping that maintains base volume, set the Retain slider to 60-70%. This preserves your manual sculpt at the roots while simulating the lower lengths.

Simulation also applicable for procedurally generated geometry.

Maya nHair System & Nucleus

Native Maya physics attributes (Stiffness, Damping, Wind Control) are highly technical and often tedious to balance. GroomKit applies optimized defaults in the background, making direct adjustment of these node attributes unnecessary for standard grooming tasks.

Info

Detailed documentation for simulation setup will be provided in a future update.

Scene Stability

Directly sliding the Time Slider backwards can cause solver instability. Always utilize the Rewind button (Right-Click Simulate) to revert simulations safely.

Hotkey Commands

Simulation Commands

Toggle Simulation (Play/Pause): 

import groomkit; groomkit.simulate.simulate()
Rewind Simulation: 
import groomkit; groomkit.simulate.rewind()
Bake Simulation (Apply): 
import groomkit; groomkit.simulate
