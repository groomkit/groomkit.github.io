XGen Guides Utilities

The Guides foldout focuses on structural adjustments to native XGen guides to streamline your 3D hair grooming workflow. It includes dedicated tools for snapping floating hair back to the scalp, securely moving roots and tips without breaking the groom, and cleaning up intersecting spline data.



Auto Select XGen Description

Maximize your 3D grooming workspace by handling tasks outside the standard XGen windows. Enabling Auto Select XGen Description instantly identifies and switches to the corresponding setting for any guides or curves clicked in the viewport, reducing long trips using manual dropdown navigation.


Clumping Automation

Centralizes map generation controls, allowing you to generate maps for multiple clumping modifiers simultaneously via:

  • The Generate Clumping Maps button.
  • The Clumping Option inside the Interactive Menu.


Indicator Icons

Description Condition Indicator
Warning - No clump guides found. Map uninitialized
Guide-based - Generated from native XGen guides. Density = 1.0
Generate-based - Generated across the mesh surface. Density ≠ 1.0

Clumping Points

Set Density to 1.0 for Guide-based maps, and any other value for Generate-based maps.

Move Guide Roots

Easily adjust root positions without shifting the rest of the guide. This localized spline manipulation is crucial for refining masks, regions, and overall clumping.

The Move Root workflow lets you reposition root CVs while preserving the guide's original shape.

  • Root Toggle: Click to temporarily convert the guide to a curve and unlock the root. Move it, then click again to apply changes and revert to a guide.
Organizing guide roots toward the center part line.

Move Guide Tips

Define the final hair silhouette and flow by repositioning the ends of the guides without affecting the overall spline shape.

The Move Tip workflow lets you adjust tip CVs while keeping the rest of the guide intact.

  • Tip Toggle: Click to temporarily convert the guide to a curve and unlock the tip. Move it, then click again to apply changes and revert to a guide.
Changing hair shape by moving tips.

Curve-to-Guide Switch

Seamlessly toggle selections between XGen guides and native Maya curves.

This lets you leverage the best sculpting tools from both workflows simultaneously.

  • Switch Toggle: Instantly convert guides to curves (or vice versa). Excellent for applying tools like localized curve smoothing directly to the guides.

Accessible Hotkeys

The Root, Tip, and Switch buttons are designed to be called repeatedly during the grooming workflow. Assigning them to custom hotkeys is highly recommended to build muscle memory and avoid UI menu diving.

Guide Overlap Check & Conversion

Heavy grooms easily hide accidental duplicates, causing XGen clumping math to explode. GroomKit lets you quickly isolate overlapping guides, or convert them back to curves for advanced deformations.

  • Distance Threshold: Defines the proximity for overlapping guides.
  • Check: Scans and selects offending duplicates for easy deletion.
  • Convert Options: Keep, Hide (safest), or Delete the original XGen guide.
  • Create Curves: Executes the guide-to-curve conversion.
