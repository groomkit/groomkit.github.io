Profile Preview

The Preview module aids viewport visibility by changing XGen guide profiles and enables quick access to color-coding for handling complex groom projects.

Guide Profile

Set width and taper for all guides in the active description, without manually selecting and changing them in the outliner.

  • Click (Apply): Reads values from the active description.
  • Double-Click (Assign): Applies taper and width values to the active description.

Viewport Color Palettes

Assign distinct colors to better separate multiple XGen descriptions visually.

  • Generate New Color Palettes: Creates a randomized list of complementary pastel colors.

Right-Click Context Menu:

  • Pick Color (Paint Mode): Sets the active Artisan brush color.
  • Flood Color (Paint Mode): Fills the current paint area with the selected color.
  • Apply Color: Changes the active description's guide color.
Separate descriptions with distinct guide colors.

Additional Colors

The preview colors are purely for viewport visualization. For functional guide color mapping, visit the Advanced Region - Density Mapping workflow.
